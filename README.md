# VELCON e-shop – prehľad skladu

Verejná stránka so stavom skladu e-shopu eshop.velcon.sk (bez obratových údajov).

- `index.html` – vygenerovaná stránka (GitHub Pages)
- `gen.py` – generátor: `python3 gen.py stock.json index.html`
- `stock.json` – snímka skladu z aplikácie Eshop Watcher (Claude artifact)

Aktualizuje sa každé ráno o 7:00 naplánovanou úlohou v Claude.
